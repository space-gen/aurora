# HuggingFace Dataset Schema

The private `SpaceGen/solarhub-*` datasets are science catalogues. Each dataset card is generated by `scripts/science_dataset.py` and documents every column, the coordinate conventions, the consensus method and the known limitations.

| Path | Contents |
|------|----------|
| `features/<split>/<date>.jsonl` | One row per solar feature |
| `observations/<date>.jsonl` | One row per annotated image |
| `stats/summary.json` | Counts, agreement and detector validation |
| `stats/manifest.json` | Row counts and SHA-256 hashes |

Raw submissions are stored in the private `SpaceGen/solarhub-archive` dataset at `annotations/<task>/<date>.jsonl`. Catalogue files are rebuilt from that archive.
